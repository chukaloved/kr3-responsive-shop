# DeviceHub — адаптивная версия (kr3-responsive-shop)

## Контрольная работа №3

Тема: «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

Дисциплина: «Фронтенд и бэкенд разработка», 3 семестр, 2026/2027 уч. год.

## Описание проекта

DeviceHub — учебный интернет-магазин компьютерной периферии (игровые мыши и микрофоны).
Проект перенесён из контрольной работы №1 (`kr1-html-css-shop`) и адаптирован под экраны
от 360px до 1440px без использования Bootstrap: только собственные медиазапросы,
Flexbox, CSS Grid и responsive images. Дополнительно выполнена проверка и доработка
доступности интерфейса.

Опубликованная версия: https://chukaloved.github.io/kr3-responsive-shop/

## Адаптивные решения

- добавлен отдельный файл `css/responsive.css`, подключён на всех страницах **после** `style.css`;
- `<meta name="viewport" content="width=device-width, initial-scale=1.0">` есть на всех страницах;
- применён подход **Mobile First**: `style.css` описывает экран 360px, `responsive.css` расширяет
  его через `min-width`; контрольные точки — 480px, 768px, 1024px, 1280px;
- размеры заголовков заданы через `clamp()` и плавно меняются с шириной экрана;
- **шапка и навигация**: до 1024px меню из 8 пунктов спрятано за кнопкой-бургером, с 1024px
  выводится в одну строку (Flexbox); без JavaScript меню остаётся видимым списком;
- **hero-блок**: высота 360 → 440 → 500 → 560px, кнопка на мобильном во всю ширину,
  фон выводится через `<picture>` (768 / 1280 / 1792px);
- **преимущества**: CSS Grid 1 → 2 → 4 колонки;
- **сетка карточек**: CSS Grid 1 → 2 → 3 колонки; в каталоге, где справа фильтр, — 2 колонки
  на 1024px и 3 на 1280px;
- **каталог**: на мобильном фильтр свёрнут в `<details>` и стоит над товарами, на desktop —
  колонка 260px слева, «липнет» при прокрутке (`position: sticky`);
- **страница товара**: на мобильном фото над описанием, с 768px — фото слева, текст справа (Grid);
- **responsive images**: правило `img, video { max-width: 100%; height: auto; }`; у карточек
  товаров — `srcset` (480w / 640w / 960w) и `sizes`; на странице товара — `<picture>`;
  у всех изображений заданы `width`/`height` (нет скачков вёрстки) и `loading="lazy"`;
  изображения переведены в WebP, имена файлов — без пробелов (hero уменьшен с 2,5 МБ до 34–118 КБ);
- **формы**: на мобильном одна колонка, кнопки друг под другом во всю ширину; с 768px — две
  колонки, длинные поля (комментарий, тема, согласие) — на всю строку; поля высотой не меньше
  44px и шрифтом 16px (iOS не увеличивает страницу при фокусе);
- **таблицы**: обёрнуты в `.table-wrapper` с `overflow-x: auto` — прокрутка только внутри
  таблицы, страница целиком вбок не прокручивается;
- **контакты**: на мобильном блоки друг под другом, с 768px — информация и форма рядом;
- **подвал**: на мобильном в колонку, с 768px — в строку;
- **модальное окно**: ширина `min(100% - 24px, 560px)`, при нехватке высоты прокручивается внутри;
- телефон в альбомной ориентации (высота до 500px): шапка не закрепляется.

## Самостоятельные доработки (сверх методических указаний)

1. **Таблица сравнения товаров** на `product.html`: на экранах до 600px каждая строка превращается
   в карточку, подписи колонок берутся из `data-label`; на планшете — прокрутка внутри
   `.table-wrapper`, на desktop — обычная таблица.
2. **Доступное меню-бургер**: `aria-expanded`, `aria-controls`, закрытие по Esc с возвратом
   фокуса на кнопку, закрытие после перехода по якорю.
3. **Container queries**: низ карточки товара (цена + кнопка) перестраивается по ширине самой
   карточки (`@container card`), а не всего экрана.
4. **Тёмная тема** по настройке системы (`prefers-color-scheme: dark`) — все цвета проверены
   на контраст.
5. **`prefers-reduced-motion`**: отключение плавной прокрутки и анимаций по настройке системы.
6. **`forced-colors`**: рамки кнопок и карточек в режиме высокой контрастности Windows.
7. **Стили для печати** (`@media print`): скрываются шапка, кнопки, фильтр, к ссылкам дописывается адрес.
8. **Форма обратной связи** на `contacts.html` и предвыбор товара на `order.html`
   по ссылке `order.html?product=...` со страницы товара.

## Доступность

- добавлена ссылка пропуска «Перейти к основному содержимому» (первый элемент при нажатии Tab);
- на каждой странице ровно один `h1`, заголовки идут без пропусков уровней;
- структура размечена `header`, `nav`, `main`, `section`, `footer`; у навигаций есть `aria-label`;
- текущая страница в меню отмечена `aria-current="page"`;
- хлебные крошки оформлены списком `<ol>` внутри `nav`;
- добавлен единый видимый фокус `:focus-visible` (рамка 3px) для ссылок, кнопок, полей и `summary`;
- контраст: цвет второстепенного текста затемнён до `#6b5f57` (6,2:1); рамки полей ввода
  затемнены до `#7f746c` — было 2,7:1, стало больше 3:1;
- у всех полей форм есть `label`, обязательные поля отмечены звёздочкой, подсказка формата
  телефона связана с полем через `aria-describedby`; поля сгруппированы `fieldset`/`legend`;
- при ошибке поле получает `aria-invalid="true"` и фокус переходит на первое неверное поле;
- сообщения об успешной отправке — `role="status"` (их зачитывает экранный диктор);
- у изображений товаров — осмысленные `alt` («Игровая мышь Logitech G Pro X чёрного цвета…»),
  фон hero — декоративный, `alt=""`;
- одинаковые кнопки «Заказать» / «Подробнее» получили уточняющие `aria-label`
  («Заказать Fifine AM8»), кнопки «Подробнее» ведут сразу к нужному товару;
- модальное окно на `<dialog>`: фокус ставится в первое поле, Esc закрывает окно, после закрытия
  фокус возвращается на кнопку, которой окно открыли; у кнопки-крестика есть `aria-label`;
- прокручиваемые таблицы доступны с клавиатуры (`tabindex="0"`, `role="region"`, подпись через `caption`);
- исправлены ошибки КР №1: опечатка «ogitech», устаревший блок «Информация для студентов»,
  учебные «преимущества» заменены на реальные.

## Lighthouse

Проверка Accessibility выполнена для страниц `index.html`, `catalog.html`, `order.html`
(Chrome DevTools → Lighthouse → категория Accessibility, режим Mobile).
Отчёты сохранены в папке `lighthouse/`.

## Проверенные ширины

| Ширина | Устройство | Результат |
|---|---|---|
| 360px | мобильный | нет горизонтального скролла, меню-бургер, одна колонка |
| 430px | крупный мобильный | нет горизонтального скролла, одна колонка |
| 768px | планшет | 2 колонки карточек, формы в 2 колонки |
| 1024px | небольшой desktop | меню в строку, каталог с фильтром слева |
| 1440px | широкий desktop | 3 колонки карточек, контент ограничен 1100px |

На каждой ширине проверены шапка, навигация, hero, сетка карточек, каталог и фильтр,
страница товара, таблицы, формы заказа и обратной связи, контакты, подвал и модальное окно.
